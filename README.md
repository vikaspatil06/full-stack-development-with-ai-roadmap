# Full Stack Development with AI — Study Lessons

A full study-lessons website: **37 lessons across 9 phases**, from HTML/CSS/JS foundations to Node.js, Firebase, Gemini AI and Android — built from the real Skillzify v2 stack.

- **Phase 0** Foundations — HTML, CSS, JavaScript, Python
- **Phase 1** Frontend — vanilla JS deep, DOM, localStorage
- **Phase 2** Backend — Node.js + Express
- **Phase 3** Data — Firebase Auth + Firestore
- **Phase 4** AI — Gemini API, prompting, RAG, agents, failover/caps
- **Phase 5** Browser Python — Pyodide, CodeMirror, Mermaid
- **Phase 6** Android — Kotlin + Jetpack Compose, Chaquopy
- **Phase 7** Full-stack capstone — Skillzify Mini
- **Phase 8** DevOps/Cloud — GitHub Actions, Render, AWS as add-on

Each lesson has deep explanations with real code from Skillzify v2, common mistakes, interview questions with model answers, a build task, and an interactive self-check quiz. Progress, XP (+20/lesson, +5/quiz), notes and mastery checks save in the browser on the device you study on.

## Timeline

~20 weeks starting **27 Nov 2026** (after exams), with DSA running in parallel throughout. React, SQL and AWS are honestly flagged as industry add-ons — they are not in Skillzify itself.
