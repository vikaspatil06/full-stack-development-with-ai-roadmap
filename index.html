How to study each lesson

You already shipped this stack once — with help. These lessons exist so every file in Skillzify becomes a file you could write from a blank page.

01 — READ ACTIVELY

Concept before syntax

Each lesson opens with the problem the technology solves and what breaks without it. Don’t skip to the code — the explanation is the lesson; the code is the proof.

02 — DO THE TASK

Every lesson ends in a build

Each lesson has a practice task that recreates a piece of Skillzify in miniature — a theme toggle, a capped API route, a two-user sync test. No task done, no next lesson.

Mastery check — the finish line

You’re done when you can honestly say all of these — out loud, without notes. This is a self-check list, not a form: nothing here is saved or submitted.

  • ✓I can build a themed, responsive page from blank HTML/CSS/JS and explain the page-load order.
  • ✓I can explain async JS and rebuild Skillzify’s lesson/XP state logic in vanilla JS and in React.
  • ✓I can read and modify the Python flowchart generators and write idiomatic Python with OOP.
  • ✓I can write an Express API with validation, rate limiting, caps, and secrets kept server-side only.
  • ✓I can design Firestore data + security rules, choose a merge rule for any field, and sketch the SQL equivalent.
  • ✓I can call Gemini with failover, design a prompt pattern, and build a small RAG system with evals.
  • ✓I can explain how Pyodide runs Python in the browser and how Chaquopy runs it in Android.
  • ✓I can ship via GitHub Actions to Render, explain the pipeline, and draw the whole Skillzify architecture from memory.

A note on courses: these lessons cover the same ground as an all-in-one course (DSA + MERN + AI) but sequenced around your codebase, with Striver (free) carrying the parallel DSA track.
