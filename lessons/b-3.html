Goal — by the end of this lessonBy the end you can style a page with selectors, colours, fonts and spacing, and explain the box model well enough to predict why an element is the size it is.

1. Selectors target elements

▶ YouTube reference — the video for this lesson

CSS rules are selector plus declarations. An element selector like p styles every paragraph; a class like .card styles anything with that class; an id like #nav styles one element. Classes are the workhorse: reusable, combinable, and the reason Skillzify can style 250 lesson cards with a handful of rules.

2. Colours and fonts

▶ YouTube reference — the video for this lesson

Colours are written as hex values like #6c7bff, rgb, or named colours. Fonts are set with font-family, usually a stack that falls back gracefully, and sized with font-size and font-weight. Skillzify loads Manrope for text and JetBrains Mono for code from Google Fonts, then falls back to system fonts if the network is slow.

▸ Code example — see the Code section below.

3. The box model

▶ YouTube reference — the video for this lesson

Every element is a box: content in the middle, then padding inside, then border, then margin outside. The trap is that by default width covers only the content, so padding and border inflate the real size. Skillzify opens its stylesheet with box-sizing: border-box on everything, making width mean the whole box. That single line prevents half of all beginner layout bugs.

4. Specificity and the cascade

▶ YouTube reference — the video for this lesson

When two rules conflict, the more specific selector wins: id beats class, class beats element. Equal specificity goes to the later rule. Keep selectors short and flat, and you will rarely need to fight the cascade or reach for the !important escape hatch. When in doubt, inspect the element in DevTools: the computed styles panel shows exactly which rule won and which ones were overridden.

5 · Check

Say your answer out loud first, then reveal. Mark “I knew it” for +5 XP each.

A box is width 200px with 20px padding on each side. How wide is it under content-box, and under border-box?

Content-box: 240px, because padding adds outside the width. Border-box: 200px, because padding is included inside the declared width.

Why prefer classes over ids for styling?

Classes are reusable and combinable, so one rule can style many elements; an id styles exactly one element and has very high specificity.

6 · Interview

Explain the CSS box model in one minute.

Content, padding, border, margin from inside out. Width defaults to content only, so border-box is the sane default that makes width mean the whole box.

How does the cascade decide which rule wins?

By specificity first — id beats class beats element — then by source order when specificity is equal.
