The system behind Skillzify's dark/light modes

Goal — by the end of this lessonBy the end you can explain the box model, why box-sizing: border-box prevents layout surprises, and exactly how Skillzify's dark/light theme works with CSS variables.

1. Every element is a box

▶ YouTube reference — the video for this lesson

The CSS box model says every element is four nested layers: content in the middle, then padding (space inside), then border, then margin (space outside). The catch: by default, width: 200px sets only the content width — padding and border are added on top, so a "200px" box with 20px padding is really 240px wide. That is the source of half of all beginner layout bugs.

▸ Code example — see the Code section below.

With border-box, width means the whole box including padding and border. Predictable. The universal reset also removes browsers' inconsistent default margins so spacing is entirely yours.

2. Layout: Flexbox and Grid

▶ YouTube reference — the video for this lesson

  • Flexbox lays items out along one axis — a nav bar, a row of cards, centering something. Main tools: display:flex, justify-content, align-items, gap.
  • Grid lays items out in two dimensions — rows and columns at once, like this page's lesson cards. Main tool: grid-template-columns.
  • Responsive design uses media queries to change the layout at widths: three columns on desktop collapse to one column on a phone.

▸ Code example — see the Code section below.

This one line is why Skillzify's content never stretches uncomfortably wide on a monitor and never touches the screen edges on a phone.

3. CSS variables: theming without duplication

▶ YouTube reference — the video for this lesson

▸ Code example — see the Code section below.

Components never hard-code colours — they reference variables. Switching themes means redefining the variables in one place, and every component follows automatically. Skillzify also swaps accent palettes the same way, with selectors like [data-accent="ocean"]. Change --primary once and every button, link and highlight on the site recolours — try it in the practice task.

The pattern to rememberVariables for values that change (colours, radii, spacing), classes for reusable components, and no colour ever typed twice. That discipline is what makes a 17-page site restyleable in an afternoon.
Watch out — common mistakes
  • Hard-coding the same colour in forty places instead of one CSS variable.
  • Forgetting box-sizing and chasing phantom layout overflows caused by padding.

3 · Code

/* The first three lines of Skillzify's style.css fix this globally */
* { margin: 0; padding: 0; box-sizing: border-box; }
.container { width: min(1140px, 92%); margin: 0 auto; }
:root {
  --bg: #0a0f22;  --text: #eef1ff;  --primary: #6c7bff;
}
[data-theme="light"] {
  --bg: #f4f6ff;  --text: #141a33;
}
body { background: var(--bg); color: var(--text); }

Say your answer out loud first, then reveal. Mark “I knew it” for +5 XP each.

With box-sizing: content-box, why is a width:200px box with 20px padding actually 240px wide?

Because content-box sets width on the content only; padding (20px each side) and border are added outside it. border-box includes them in the declared width.

How does Skillzify's dark/light toggle change the whole site by changing so little?

All components use CSS variables like var(--bg). The toggle only changes the data-theme attribute on the html element; the [data-theme] block redefines the variables and everything repainting from them follows.

6 · Interview

Explain the CSS box model and the content-box trap.

Content, padding, border, margin. With content-box, declared width covers content only, so padding/border inflate the real size; border-box makes width mean the whole box.

How would you implement a dark/light theme cleanly?

CSS variables for all themed values, swapped by a data-theme attribute on the root element; components only ever reference variables.
