Goal — by the end of this lessonBy the end you can write a valid HTML page from scratch using headings, paragraphs, links, images and lists, and explain what the browser does with each tag.

1. HTML is structure, not looks

▶ YouTube reference — the video for this lesson

HTML (HyperText Markup Language) describes what things are, not how they look. A heading is a heading, a paragraph is a paragraph, and a link is a link. Colour and layout belong to CSS, behaviour belongs to JavaScript. Every Skillzify page starts as plain HTML text that the browser turns into a tree of elements called the DOM.

2. The essential tags

▶ YouTube reference — the video for this lesson

Most pages use a small set of tags. Headings run from h1 (the page title, used once) down to h6. Paragraphs use p. Links use a with an href attribute. Images use img with src and alt text that screen readers read aloud. Lists come in two kinds: ul for unordered bullets and ol for numbered steps, each holding li items.

▸ Code example — see the Code section below.

3. Nesting and attributes

▶ YouTube reference — the video for this lesson

Tags nest inside each other like boxes inside boxes, and every opening tag needs its closing tag. Attributes add information: href tells a link where to go, src tells an image what to load. A page that validates cleanly renders predictably in every browser, which is why Skillzify keeps its markup simple and consistent across all 17 pages.

4. Why this matters for Skillzify

▶ YouTube reference — the video for this lesson

Skillzify lessons, exercises and reference entries are all HTML at heart. When you can read raw HTML fluently, you can debug any page by viewing its source instead of guessing what went wrong.

Why should a page have exactly one h1?

The h1 is the page title. Screen readers and search engines use it to understand the page topic; multiple h1s blur that meaning.

What is alt text on an image actually for?

It describes the image for screen readers and shows when the image fails to load. It is accessibility, not decoration.

6 · Interview

Explain the difference between a block element and an inline element.

Block elements like p and h1 start on a new line and take full width; inline elements like a and strong flow inside a line of text.

What does DOCTYPE do?

It tells the browser to render the page in standards mode instead of quirks mode, so layout rules behave consistently.
