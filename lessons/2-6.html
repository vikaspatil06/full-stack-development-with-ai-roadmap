1. Generators: values on demand

▶ YouTube reference — the video for this lesson

▸ Code example — see the Code section below.

A normal function builds a whole list and returns it; a generator yields one item at a time. For big inputs — scanning thousands of lines of learner code — that is the difference between fine and out-of-memory. Rule of thumb: if the caller processes items one by one, yield them.

2. JSON and files: Python's border with every other system

▶ YouTube reference — the video for this lesson

▸ Code example — see the Code section below.

The with block is a context manager: the file closes even if an exception hits mid-write. json.load/dump work on files; loads/dumps work on strings. This is the same JSON the browser sends your Express server in Module 3 — one format, every border.

3. Trace the real pipeline: code → flowchart

▶ YouTube reference — the video for this lesson

flowchart-gen.py reads Python code and emits a JSON list of nodes and edges; flowchart-algo.py does the same from pseudocode. The browser then renders that JSON with Mermaid (Module 6). Notice the architecture: Python never draws anything. It produces structured data, and a specialist renderer draws. Separating "decide" from "draw" is what makes both halves replaceable.

Error handling habitWrap file and JSON work in try/except with specific exceptions (FileNotFoundError, json.JSONDecodeError) and a message that says which input failed. A crashed generator with no context is a debugging session; with context, it's a one-line fix.
Watch out — common mistakes
  • Opening files without a context manager, leaking handles on exceptions.
  • Loading a huge file fully into memory when a generator would stream it.

Why use yield instead of returning a list when scanning a large file?

The generator produces items one at a time, so memory stays flat regardless of input size; a returned list materialises everything at once.

What does the with statement guarantee for file work?

The file is closed when the block exits — including when an exception is raised inside it.

7 · Interview ▾

Generator vs normal function — the difference?

A generator yields values lazily one at a time and pauses between them; a normal function builds and returns the complete result at once.

Why separate 'produce JSON' from 'render diagram' in the flowchart feature?

Decoupling: the parser and renderer evolve independently, the JSON is independently testable, and other renderers can reuse it.
