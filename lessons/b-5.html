1. Variables: const first, let when it changes

▶ YouTube reference — the video for this lesson

JavaScript has three ways to declare a variable, but only two should be used. const is for values that never get reassigned, let is for values that do, and var is legacy with confusing scoping rules. Skillzify code uses const by default, which makes it obvious at a glance what can change and what cannot.

2. Data types

▶ YouTube reference — the video for this lesson

The primitives are number, string, boolean, null, undefined, symbol and bigint. Strings hold text, numbers hold all numeric values (there is no separate integer type), booleans are true or false, and null means deliberately empty while undefined means never assigned. Objects and arrays hold structured data and are covered in the next lesson.

▸ Code example — see the Code section below.

3. Operators

▶ YouTube reference — the video for this lesson

Arithmetic covers plus, minus, multiply, divide and remainder. Comparison operators like === and > return booleans. Always use strict equality ===: loose == coerces types and produces surprises like "5" == 5 being true. Logical operators &&, || and ! combine conditions.

4. The console is your lab

▶ YouTube reference — the video for this lesson

console.log prints values, console.table prints arrays and objects neatly, and the browser DevTools console lets you run any JavaScript against the live page. Skillzify exposes helpers like Skillzify.toast on the window object precisely so you can call them from the console while learning.

When do you use const, and when let?

const by default, for anything never reassigned; let only when the value genuinely changes, like a counter or a running total.

Why is === safer than ==?

=== compares value and type with no coercion; == converts types first, so "5" == 5 is true and hides bugs.

7 · Interview ▾

What is the difference between null and undefined?

null is an intentional empty value assigned by the programmer; undefined means a variable was declared but never given a value, or a property does not exist.

What does typeof null return, and why is it famous?

It returns "object" — a historic bug in the language that was never fixed because too much code depends on it.
