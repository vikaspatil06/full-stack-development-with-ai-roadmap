1. A textarea is not an editor

▶ YouTube reference — the video for this lesson

Learners need line numbers, syntax colours, bracket matching and sane tabs. CodeMirror provides that layer: it renders an editable surface and tokenises code — a Python mode scans the text and labels each piece (keyword, string, number, comment) so themes can colour them. Skillzify pins CodeMirror 5.65.16 with Python mode and selectable themes (Dracula, Nord, Monokai).

2. Editor state as a feature surface

▶ YouTube reference — the video for this lesson

Once code is data via getValue(), features compose: Run sends it to Pyodide (Lesson 6.1); the Stuck? button sends code + the current error to the AI hint route; exercise checks compare output. Every compiler feature is "editor state → some consumer".

3. Version honesty: CM5 vs CM6

▶ YouTube reference — the video for this lesson

Skillzify uses CodeMirror 5 — stable, simple, one global script. CodeMirror 6 is a ground-up rewrite (modular, better mobile/accessibility) at the cost of a build step and new APIs. Knowing what you run and why beats chasing the newest major.

Mobile reality checkCode editing on phones is painful — small targets, autocorrect fighting code. Skillzify mitigates with sensible defaults, but when you test your runner (Lesson 6.1 task), test it on your own phone before calling it done.

How does syntax highlighting actually work in CodeMirror?

A language mode tokenises the text — labelling keywords, strings, comments — and the theme maps token types to colours. It's analysis, not stored formatting.

Why is editor.getValue() such an important API for the product?

It turns the learner's code into data any feature can consume: the Pyodide runner, exercise checks, and the AI Stuck? hint flow.

6 · Interview

What does a code editor library actually do beyond a textarea?

Tokenisation-driven highlighting, line numbers, indentation handling, bracket matching, and a state API (getValue/setValue) that features build on.

Your compiler needs an 'AI hint' feature. What data do you send?

The current editor code and the latest error/output — enough context for a grounded hint — to my server route, which calls the model with a Socratic prompt.
