CSS Grid & Flexbox Deep — Layout Like a Professional

Two layout systems, one decision

Goal — by the end of this lessonBy the end you can build two-dimensional layouts with grid-template-areas and fr units, make grids responsive with auto-fit and minmax, align precisely with Flexbox, and choose between Grid and Flexbox with reasons.

1. Grid areas: draw the layout in text

▶ YouTube reference — the video for this lesson

grid-template-areas lets you sketch a layout as ASCII art: each quoted string is a row, each name is a region, and repeating a name spans it across cells. Assign children with grid-area and the page skeleton — header, sidebar, main, footer — is readable at a glance. Rearranging for mobile becomes rewriting the sketch inside a media query instead of touching the HTML. It is the most maintainable way to build app shells and dashboards, where the layout itself is the design.

2. fr units, auto-fit and minmax: grids that size themselves

▶ YouTube reference — the video for this lesson

The fr unit divides leftover space proportionally: 1fr 2fr gives the second column twice the first, after fixed sizes and gaps are subtracted. Combined with repeat(auto-fit, minmax(240px, 1fr)), a grid fits as many columns of at least 240px as the container allows and stretches them to fill — a fully responsive card grid with zero media queries. Skillzify's lesson cards use exactly this thinking: equal-height rows where every card in a row matches, whatever the screen width.

3. Flexbox alignment, properly understood

▶ YouTube reference — the video for this lesson

Flexbox confusion almost always comes from forgetting that the axes swap with flex-direction. In a row, justify-content works horizontally and align-items vertically; in a column they trade places. flex-grow distributes leftover space to items that ask for it, flex-shrink decides who gives space back, and flex-basis sets the starting size. The professional habit: use gap for spacing instead of margins on children, and let margin-left: auto push one item to the far end of a nav bar — the two tricks that replace most alignment hacks.

4. Grid or Flexbox: the decision rule

▶ YouTube reference — the video for this lesson

Grid is for layout in two dimensions where rows and columns must align with each other: page skeletons, card grids, dashboards. Flexbox is for one dimension where items flow and wrap: nav bars, button rows, chip lists, centring a single element. The test is whether the items need to line up across rows. If a card in row two must align with the card above it, that is Grid; if items can be different widths and simply flow, that is Flexbox. Real pages use both — Grid for the page, Flexbox inside each region — and knowing which layer you are in is most of professional layout.

4 · Code ▾

▶ Run works for JavaScript snippets below — it runs in a sandboxed worker with a 2-second timeout. Python, HTML and CSS snippets are read-only here.

.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas:
    "nav nav"
    "side main"
    "side foot";
  gap: 16px;
}
.nav { grid-area: nav; }
.side { grid-area: side; }
.main { grid-area: main; }
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 14px;
}

Say your answer out loud first, then reveal. Mark “I knew it” for +5 XP each — or “Didn’t know it” to count it as a miss. Your score shows below.

What does 1fr 2fr mean in grid-template-columns?

After fixed sizes and gaps are subtracted, the leftover space is split into three parts: the first column gets one part, the second gets two.

How does repeat(auto-fit, minmax(240px, 1fr)) make a grid responsive without media queries?

The browser fits as many columns of at least 240px as the container allows and stretches them equally to fill the row, adding or removing columns as the width changes.

Why do justify-content and align-items seem to swap in a column flex container?

They are defined relative to the main and cross axes, and flex-direction: column makes the main axis vertical — so justify works vertically and align horizontally.

When must a layout be Grid rather than Flexbox?

When items must align across both rows and columns — page skeletons and card grids. Flexbox flows items in one dimension without cross-row alignment.

Bonus round — flashcards (+5 XP each)

Define each term out loud before revealing. These count toward your score below.

What is “grid-template-areas”?

A way to define a grid layout as named text rows, so the page skeleton reads like a sketch and rearranges by rewriting the sketch.

What is “fr unit”?

A fraction of the leftover space in a grid container, after fixed tracks and gaps are subtracted.

What is “auto-fit + minmax”?

A responsive grid recipe: fit as many columns of at least a minimum size as possible, stretching them to fill.

What is “Main axis”?

The direction Flexbox lays items out — horizontal for row, vertical for column; justify-content works along it.

What is “flex-grow / shrink / basis”?

How a flex item claims leftover space, gives space back under pressure, and its starting size before either happens.

What is “Grid vs Flexbox rule”?

Two dimensions with cross-row alignment: Grid. One dimension with flowing items: Flexbox.

7 · Interview ▾

Explain the difference between Grid and Flexbox in one minute.

Grid lays out in two dimensions with rows and columns that align; Flexbox lays out in one dimension along a single axis. Use Grid for page structure and card grids, Flexbox for nav bars, rows and centring.

How do you make equal-height cards in a row?

With Grid's default stretch alignment and grid-auto-rows: 1fr, every card fills its row height; inside the card, a flex column with the footer pushed down by margin-top: auto keeps actions aligned.
