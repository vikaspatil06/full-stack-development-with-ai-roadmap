Goal — by the end of this lessonBy the end you can use AND, OR, XOR and shifts fluently, apply the classic tricks — n & (n-1), XOR cancellation, bit counting — and explain why each works.

1. The four operations and what they mean

▶ YouTube reference — the video for this lesson

Bitwise operators work on each bit independently. AND keeps a 1 only where both bits are 1 — used for masking, as in n & 1 to test oddness. OR sets a bit where either is 1 — used to turn flags on. XOR is 1 where the bits differ — the workhorse of this lesson. Shifts move bits left or right: n << 1 doubles n, n >> 1 halves it. The mental shift is to stop seeing numbers and start seeing rows of switches: every trick below is just a statement about those switches.

2. XOR cancellation: pairs disappear

▶ YouTube reference — the video for this lesson

XOR has three properties that do all the work: x ^ x = 0, x ^ 0 = x, and it is commutative and associative, so order does not matter. XOR every element of an array where all values appear twice except one, and the pairs cancel to zero, leaving the single element — Single Number in one pass, O(n) time, O(1) space. The same idea finds the missing number in 0..n by XORing the range with the array. Whenever a problem says everything appears twice except, think XOR before reaching for a hash map.

3. n & (n-1): erasing the lowest set bit

▶ YouTube reference — the video for this lesson

Subtracting 1 from n flips its lowest set bit to 0 and every bit below it to 1. ANDing n with n−1 therefore clears exactly the lowest set bit and leaves the rest untouched. That gives the fastest way to count set bits — loop while n is non-zero, clear one bit per iteration, count iterations — which runs in time proportional to the number of set bits, not the number of bits. It also tests powers of two in one line: a positive n is a power of two exactly when n & (n-1) is zero, because powers of two have a single set bit.

4. Counting bits and building intuition

▶ YouTube reference — the video for this lesson

Counting Bits asks for the popcount of every number up to n, and the DP relation falls out of the bit view: bits[i] = bits[i >> 1] + (i & 1) — the count for i is the count for i halved, plus its lowest bit. To build fluency, practise the small moves until they are reflexes: test bit k with n & (1 << k), set it with OR, clear it with AND against the complement, toggle it with XOR. Interview bit questions are rarely deep; they reward exactly this fluency plus the two big tricks above.

def single_number(nums):
    result = 0
    for x in nums:
        result ^= x
    return result

def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count

# XOR cancels pairs; n & (n-1) clears the lowest set bit each round.

Why does XORing the whole array find the single unpaired element?

Pairs cancel because x ^ x = 0, and x ^ 0 = x, so after all cancellations only the unpaired element remains. Order does not matter because XOR is commutative and associative.

What does n & (n-1) do, exactly?

It clears the lowest set bit of n and leaves all higher bits unchanged, because subtracting 1 flips that bit off and turns the bits below it on.

How do you test whether n is a power of two in one expression?

n &gt; 0 and n &amp; (n - 1) == 0: a power of two has exactly one set bit, and clearing it leaves zero.

What is the DP relation for counting bits up to n?

bits[i] = bits[i &gt;&gt; 1] + (i &amp; 1): the popcount of i is the popcount of i halved plus its lowest bit.

Bonus round — flashcards (+5 XP each)

Define each term out loud before revealing. These count toward your score below.

What is “XOR”?

Bitwise exclusive-or: 1 where bits differ. x ^ x = 0 and x ^ 0 = x, so pairs cancel — the basis of Single Number.

What is “Mask”?

A bit pattern used with AND to isolate specific bits, like n &amp; 1 to test oddness.

What is “n & (n-1)”?

Clears the lowest set bit of n; the engine behind fast bit counting and the power-of-two test.

What is “Popcount”?

The number of set bits in a number, computed by clearing bits one at a time or with a DP relation.

What is “Shift”?

Moving bits left or right: left shift by 1 doubles, right shift by 1 halves (for non-negative numbers).

What is “Set / clear / toggle bit k”?

OR with (1 &lt;&lt; k) sets it, AND with the complement clears it, XOR with (1 &lt;&lt; k) toggles it.

7 · Interview ▾

Find the element that appears once when all others appear twice, in O(1) space.

XOR all elements. Pairs cancel to zero and the single element survives, giving O(n) time and O(1) space.

How do you count set bits faster than checking all 32 positions?

Repeatedly clear the lowest set bit with n &amp;= n - 1 and count the iterations. The loop runs once per set bit, not once per bit position.
