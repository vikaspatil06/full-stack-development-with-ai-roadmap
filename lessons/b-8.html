1. Conditions and loops

▶ YouTube reference — the video for this lesson

Python conditions use if / elif / else with indentation instead of braces. Loops use for over any sequence and while while a condition holds. Indentation is not style in Python — it is syntax, and inconsistent indentation is a hard error, not a warning.

2. Functions

▶ YouTube reference — the video for this lesson

Define functions with def, pass parameters, and return values. Default arguments make a parameter optional. Python functions can return multiple values as a tuple, which is how small helper functions in Skillzify's flowchart code return both a result and a status.

▸ Code example — see the Code section below.

3. Lists

▶ YouTube reference — the video for this lesson

Lists are ordered, mutable sequences. Index them, slice them, append to them, and loop over them directly instead of by index. List comprehensions build a new list from an old one in a single readable expression — the idiomatic Python way to map and filter.

4. Dicts

▶ YouTube reference — the video for this lesson

Dicts map keys to values and are Python's default data structure: progress["p-1"] looks up a lesson in constant time. Skillzify's flowchart parser produces nested dicts as its intermediate JSON, and the web side reads that JSON directly — one data shape, two languages. Dicts also power JSON itself, so every dict you write is practice for the real pipeline that carries flowchart data from Python to the browser.

3 · Code

def grade(score):
    if score >= 90:
        return "A"
    elif score >= 50:
        return "Pass"
    return "Fail"

lessons = [{"id": "p-1", "xp": 20}, {"id": "p-2", "xp": 30}]
progress = {"p-1": True, "p-2": False}
total = sum(l["xp"] for l in lessons if progress[l["id"]])
print(grade(85), total)   # Pass 20

Why iterate a list directly instead of by index in Python?

Direct iteration is shorter, cannot go out of bounds, and reads as intent. Indexes are only needed when the position itself matters.

When do you pick a dict over a list?

When you look things up by a key, like a lesson id. A dict lookup is O(1); scanning a list for an id is O(n).

6 · Interview

What is a list comprehension, and when is it the right choice?

A one-line expression building a list from another iterable, optionally filtered. Right for simple map/filter jobs; wrong when the logic needs several statements.

How does Python indentation relate to correctness?

Indentation defines block structure — it is syntax, not formatting. Wrong indentation changes meaning or raises an IndentationError.
