1. The shape of a call

▶ YouTube reference — the video for this lesson

Skillzify talks to Gemini by REST fetch from server.js — no SDK. A generate-content call is a POST with the model in the URL and the conversation as structured contents:

▸ Code example — see the Code section below.

Note the discipline from Module 3: the key is concatenated server-side from env vars, the user's input was validated before this code runs, and the response path is checked before use — model APIs return errors, refusals and empty candidates, and blind indexing crashes.

2. Streaming: answer as it's written

▶ YouTube reference — the video for this lesson

The :streamGenerateContent variant sends the reply in chunks. Forward each chunk to the browser and the tutor feels alive instead of frozen for 8 seconds. Cost: more moving parts — partial JSON, mid-stream errors, client rendering per chunk. Skillzify's baseline is the simple non-streamed call; streaming is an upgrade you add when latency is felt, not by default.

3. Structured output: JSON you can trust (mostly)

▶ YouTube reference — the video for this lesson

For quizzes and drills, prose is useless — the UI needs data. Ask for JSON explicitly (response MIME type / schema where supported), then parse defensively: wrap in try/catch, validate field types, and have a fallback (retry once with a repair prompt, or degrade to plain text). "The model returned almost-JSON" is a normal Tuesday.

SDK vs REST — the honest tradeAn SDK gives typed helpers and quieter upgrades; REST gives zero dependencies and total visibility — which is why Skillzify's approach doubles as a teaching tool. Either is defensible; hiding the request entirely is not, when you're learning.

const url = "https://generativelanguage.googleapis.com/v1beta/models/"
          + model + ":generateContent?key=" + apiKey;
const res = await fetch(url, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    systemInstruction: { parts: [{ text: SYSTEM_PROMPT }] },
    contents: [{ role: "user", parts: [{ text: question }] }],
    generationConfig: { temperature: 0.4 }
  })
});
const data = await res.json();
// reply text lives at data.candidates[0].content.parts[0].text

Where does the Gemini API key appear in a correct Skillzify-style call, and where never?

Server-side only — concatenated into the request in server.js from env vars. Never in browser code, where view-source would expose it.

Why parse model JSON defensively even when you requested JSON output?

Models occasionally return malformed, truncated or prose-wrapped output; unguarded JSON.parse turns a model hiccup into a server crash.

7 · Interview ▾

Describe the full path of one AI request in your app.

Browser → my Express route (validate, rate-limit, cap) → server attaches key and calls Gemini → response checked and normalised → JSON back to the browser, with a fallback path at every failure point.

Streaming vs non-streaming — when do you pay streaming's complexity cost?

When perceived latency hurts the experience (long tutor replies, chat). For short structured outputs, a single response is simpler and fast enough.
