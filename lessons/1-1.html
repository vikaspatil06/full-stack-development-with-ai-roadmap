Spread creates a new array or object instead of modifying the old one. That habit — never mutate, always produce a new version — is the foundation of predictable state, and it is exactly how React state updates work later.

Why prefer creating a new array with spread over push()-ing into the old one?

Mutation makes old references change silently, which breaks change detection and reasoning about state; a new array makes the update explicit and traceable.

Which array method turns a list of results into a single total XP number?

reduce — it folds the array into one accumulated value.

7 · Interview ▾

map vs filter vs reduce — one line each.

map transforms every item, filter keeps items passing a test, reduce folds the array into a single accumulated value.

Why does React culture dislike mutation?

Change detection and rendering rely on new references signalling new state; mutating in place hides changes and creates stale-UI bugs.
