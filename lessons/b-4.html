Goal — by the end of this lessonBy the end you can lay out a page with Flexbox and Grid, position elements deliberately, and make a layout collapse cleanly on a phone with media queries.

1. Flexbox: layout along one axis

▶ YouTube reference — the video for this lesson

Flexbox arranges items in a row or a column. Set display: flex on the parent, then control spacing with justify-content along the main axis, align-items across it, and gap for even spacing. It is the right tool for nav bars, rows of cards, and centring one element inside another — the three layouts beginners fight with most.

2. Grid: layout in two dimensions

▶ YouTube reference — the video for this lesson

Grid handles rows and columns together. grid-template-columns: repeat(3, 1fr) makes three equal columns; gap spaces them. Skillzify uses Grid for its lesson cards and Flexbox inside each card. Rule of thumb: one axis, Flexbox; two axes, Grid.

3. Positioning

▶ YouTube reference — the video for this lesson

Static is the default flow. Relative nudges an element from its normal spot. Absolute positions it against the nearest positioned ancestor, which is how badges and copy buttons sit inside code blocks. Fixed pins it to the viewport. Sticky, used for Skillzify's top bar, scrolls normally until it hits the top, then stays put.

4. Responsive basics

▶ YouTube reference — the video for this lesson

Media queries change the layout at a width breakpoint: three columns become one below 820px. Combine that with fluid widths like width: min(1140px, 92%) and images that never exceed their container, and one page works from a phone to a monitor without a separate mobile site. A handy habit is to design the mobile layout in a narrow browser window first, then widen it and add breakpoints only when the design starts to strain.

When do you reach for Grid instead of Flexbox?

When the layout needs rows and columns at once, like a card grid. Flexbox is for a single row or column.

What does position: sticky do that fixed does not?

Sticky scrolls with the page until it reaches its threshold, then sticks; fixed is pinned to the viewport from the start and never scrolls.

7 · Interview ▾

Explain the difference between justify-content and align-items.

Justify-content aligns along the main axis (row direction by default); align-items aligns across the cross axis. Swap them mentally when flex-direction changes.

How would you make a page responsive without a framework?

Fluid widths, flexible images, Grid/Flexbox layouts, and media queries that reflow the layout at breakpoints — mobile-first if possible.
