How Skillzify renders lessons from data files

1. The core idea: render from data, never hand-write DOM

▶ YouTube reference — the video for this lesson

Beginners build UI by creating elements one by one. Professionals keep a single source of truth — a data structure — and write a render function that turns data into DOM. Change the data, re-run render, and the UI is correct by construction. Skillzify's Learn page works exactly like this.

2. Content as code

▶ YouTube reference — the video for this lesson

Skillzify has no CMS and no content database. The curriculum is JavaScript data files: lessons-b/i/a.js hold the 250 lessons, practice-data.js holds 150 exercises, reference-data.js holds 127 entries. learn.js reads those arrays and renders the journey path; lesson.js renders one lesson. Adding a lesson means adding a data object, not touching rendering code.

3. Derived state: mastery and review scheduling

▶ YouTube reference — the video for this lesson

Two of Skillzify's smartest features are pure functions over that data plus the learner's progress:

  • Mastery Engine (mastery.js) scores each section 0–100 from completed lessons, exercise accuracy and recency — then the "Next Up" card is just "the highest-value incomplete item", computed, not stored.
  • Spaced repetition (review.js) implements SM-2: intervals grow 1 → 3 → 7 → 14 → 30 → 60 days as you succeed. The schedule is derived from last-review date + ease, never a hand-maintained list.

The lesson: store facts, compute views. Store "lesson X completed on date D with score S" — compute mastery, streaks and next-up on demand. Stored derived values drift out of sync; computed ones can't.

Bridge to ReactThis is precisely React's mental model — components render from state, and derived values are computed during render. Learn it in vanilla first and React becomes a syntax, not a new idea.
Watch out — common mistakes
  • Storing derived values (like a mastery score) that can drift from the facts they're computed from.
  • Hand-building DOM node by node instead of rendering from a data array.

Why store raw facts and compute mastery instead of storing the mastery score?

Computed values are always consistent with the underlying facts; stored derived values can drift when facts change through another path (like sync from Android).

How does Skillzify add a new lesson without changing rendering code?

Lessons are data files; learn.js renders whatever objects exist in the arrays. A new lesson is a new data object.

7 · Interview ▾

What does 'UI is a function of state' mean in practice?

One source-of-truth data structure and a render function; change the data, re-render, and the UI is correct by construction — no manual DOM bookkeeping.

Why store content as data files instead of a CMS, in Skillzify's case?

Lessons ship with the code: versioned in git, zero extra infrastructure, instant loads; rendering code never changes when content is added.
