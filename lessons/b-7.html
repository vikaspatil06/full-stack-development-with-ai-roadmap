1. Setup: Python and VS Code

▶ YouTube reference — the video for this lesson

Install Python from python.org and tick the box that adds it to PATH, then install VS Code and the Python extension. Verify with python --version in the terminal. Skillzify's flowchart generators are Python scripts run exactly this way, so this setup is not a detour — it is the real toolchain.

2. Print and input

▶ YouTube reference — the video for this lesson

print writes to the screen and input reads a line of text from the user. Input always returns a string, so convert it with int or float before doing maths. This string-or-number confusion is the single most common beginner bug in Python.

▸ Code example — see the Code section below.

3. Variables and types

▶ YouTube reference — the video for this lesson

Python variables need no declaration and no type annotation: assignment creates them. The core types are int, float, str, bool, plus the collections covered next lesson. Variables are names bound to values, and rebinding a name to a new value is normal and cheap.

4. Dynamic typing, with discipline

▶ YouTube reference — the video for this lesson

Because types are checked at runtime, a variable can hold a string in one line and a number in the next. That freedom is convenient and dangerous: name variables clearly, and convert input explicitly at the boundary, so type errors surface where the data enters, not deep inside the program. Run your script often as you write it: a small program tested line by line is far easier to fix than a long one run for the first time at the end.

Why does input() need int() around it before maths?

input() always returns a string. Adding two strings concatenates them, and comparing a string to a number raises a TypeError.

What does 10 // 3 return, and how is it different from 10 / 3?

10 // 3 is 3, floor division that drops the remainder; 10 / 3 is 3.333..., true division.

6 · Interview

Is Python statically or dynamically typed?

Dynamically typed: variable types are decided at runtime and a name can be rebound to a value of a different type.

What happens if you add a string and a number in Python?

A TypeError at runtime. Python refuses implicit conversion between str and int, unlike JavaScript.
