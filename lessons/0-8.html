CSS Animations & Transitions — Motion with Purpose

Small movements that teach, not distract

1. Transitions: between two states

▶ YouTube reference — the video for this lesson

A transition animates a property change over time: a button darkens on hover, a card lifts slightly, a theme toggle fades instead of snapping. You declare which property, how long, and what easing curve. Skillzify's buttons and cards use short 150–250ms transitions — long enough to feel smooth, short enough to never feel slow.

2. Keyframes: full choreography

▶ YouTube reference — the video for this lesson

When a change has more than two states, keyframes describe the whole sequence: a spinner rotating, a toast sliding in, a skeleton shimmer. The animation property names the keyframes, sets duration, iteration and fill mode. Reusable keyframe names in one stylesheet keep motion consistent across the site.

▸ Code example — see the Code section below.

3. Animate the cheap properties

▶ YouTube reference — the video for this lesson

Transform and opacity run on the compositor thread and skip layout and paint, so they stay at 60 frames per second even on weak phones. Animating width, height, top or margin forces layout recalculation every frame and stutters. If a motion idea needs a layout property, redesign the motion instead of accepting the jank.

4. Respect reduced motion

▶ YouTube reference — the video for this lesson

Some users experience motion sickness or distraction from animation. The prefers-reduced-motion media query lets you disable or shorten animations for them. It is one block of CSS, it costs nothing, and it is the difference between polish and a product that harms part of its audience.

3 · Code

.btn { transition: background 0.2s ease, transform 0.2s ease; }
.btn:hover { transform: translateY(-2px); }
@keyframes slideIn {
  from { opacity: 0; transform: translateY(8px); }
  to { opacity: 1; transform: translateY(0); }
}
.toast { animation: slideIn 0.25s ease-out; }

Why animate transform instead of top or margin?

Transform runs on the compositor and skips layout and paint; top and margin force layout recalculation every frame, which stutters.

What does prefers-reduced-motion do, and why use it?

It detects the user's OS setting asking for less animation. Honouring it prevents motion sickness and distraction for users who need it.

6 · Interview

What is the difference between a transition and an animation?

A transition animates between two states when a property changes; an animation runs a defined keyframe sequence, possibly looping, without needing a state change.

How do you keep animations at 60fps?

Animate only transform and opacity, keep durations short, and avoid triggering layout or paint on each frame.
