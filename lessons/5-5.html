Goal — by the end of this lessonBy the end you can design a prompt for a new AI feature using role, context, few-shot examples and output constraints — and classify Skillzify's 15 modes by the pattern each one uses.

1. The anatomy of a prompt that works

▶ YouTube reference — the video for this lesson

▸ Code example — see the Code section below.

Four levers, in order of impact: role + task clarity (who you are, what done looks like), rules/constraints (length, format, prohibitions), examples (few-shot: show 1–3 input→output pairs — the single strongest technique for consistent format), and the user's actual input, clearly delimited so the model never confuses instructions with data.

2. Patterns hiding in Skillzify's 15 modes

▶ YouTube reference — the video for this lesson

  • Socratic hinting (Ask AI on questions): rules forbid the final answer — the product value is the restraint.
  • Persona + rubric (viva mode): the model plays an examiner with a scoring rubric in the prompt.
  • Transform (flowchart explain / flowchart-to-code): input format A, output format B, one worked example pins the mapping.
  • Generate-then-format (quizzes, drills): generation rules plus the structured-output discipline from Lesson 5.2.

3. Chain-of-thought, used carefully

▶ YouTube reference — the video for this lesson

Asking the model to reason step by step before answering improves hard problems — but the reasoning is also billable output and latency. Use it where accuracy pays (grading, debugging), skip it for lookups and formatting.

Prompts are codeVersion them, change one variable at a time, and keep a small set of test inputs you re-run after every prompt edit (that's the seed of Lesson 5.6's evals). A prompt changed on vibes regresses silently.

What is few-shot prompting and why is it so effective for format consistency?

Including a few input→output examples in the prompt; the model pattern-matches the demonstrated format far more reliably than it follows format descriptions.

Why does Skillzify's Ask AI mode forbid giving the final answer?

Because the product is learning, not answers — the restraint is the feature. The rule lives in the prompt because the model would otherwise helpfully solve it.

7 · Interview ▾

How do you make an LLM feature's output consistent?

Constrain the format (ideally structured JSON), pin it with few-shot examples, low temperature for factual modes, validate output server-side, and regression-test prompts against a fixed input set.

What is prompt injection and one mitigation?

User input that tries to override the system instructions. Mitigate with clear delimiters, instruction hierarchy (system rules restated), output validation, and never letting model output directly trigger privileged actions.
