Goal — by the end of this lessonBy the end you can write if/else logic, loops, reusable functions, and work with arrays and objects — the four constructs behind nearly all of Skillzify's client code.

1. Conditions choose a path

▶ YouTube reference — the video for this lesson

if / else if / else runs different code based on a boolean test. A ternary, condition ? a : b, is the compact form for simple either-or values. Skillzify uses conditions everywhere: whether a lesson is unlocked, whether a streak continues, whether the user is signed in.

2. Loops repeat work

▶ YouTube reference — the video for this lesson

A for loop runs a fixed number of times, a while loop runs until a condition fails, and for...of walks through an array's values directly. Prefer for...of or array methods over manual index loops when you do not need the index — the code reads like a sentence instead of bookkeeping.

▸ Code example — see the Code section below.

3. Functions package behaviour

▶ YouTube reference — the video for this lesson

A function takes inputs, does work, and returns a result. Named functions, function expressions and arrow functions all exist; arrow functions are the compact form used in callbacks. The golden rule is one job per function, so each one is testable and its name explains it.

4. Arrays and objects

▶ YouTube reference — the video for this lesson

Arrays are ordered lists with methods like push, map and filter. Objects are key-value records accessed with dot notation. Skillzify's entire curriculum is arrays of lesson objects exactly like the example above, and progress is an object keyed by lesson id.

3 · Code

const lessons = [
  { id: "b-1", title: "Intro", xp: 20 },
  { id: "b-2", title: "Loops", xp: 20 }
];
function totalXp(list) {
  let total = 0;
  for (const lesson of list) { total += lesson.xp; }
  return total;
}
const user = { name: "Vikas", level: 3 };
console.log(user.name, totalXp(lessons));

Why prefer for...of over a C-style index loop when you only need values?

It removes index bookkeeping, so there is no off-by-one error possible and the intent — visit each item — is obvious.

What is the difference between an array and an object?

An array is an ordered list accessed by index; an object is a record accessed by named keys.

6 · Interview

What does a function return if it has no return statement?

undefined. The function still runs, but calling code receives undefined.

Explain the difference between a function declaration and an arrow function, briefly.

Declarations are hoisted and have their own this; arrow functions are compact, not hoisted the same way, and inherit this from the surrounding scope.
