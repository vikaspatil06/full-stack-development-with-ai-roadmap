2. Middleware: the chain every request walks

▶ YouTube reference — the video for this lesson

app.use registers middleware — functions that run in order before the route handler, each receiving (req, res, next). JSON parsing, logging, auth checks and rate limiting are all middleware. Forget next() and the request hangs forever; Skillzify's server composes its protections exactly this way.

3. Static + API in one server

▶ YouTube reference — the video for this lesson

express.static serves Skillzify's 17 HTML pages and assets, while POST /api/* routes handle AI calls. One process, two jobs — simple to deploy on Render, and the browser only ever talks to the API for things that need secrets or shared limits (Module 3.4).

Status codes are a contract200 success, 400 the client sent something invalid, 401/403 auth problems, 429 rate limited, 500 your bug. Frontend code branches on these — inventing your own shapes per route makes the client a mess.

3 · Code

const express = require("express");
const app = express();

app.use(express.json());                 // parse JSON bodies
app.use(express.static("public"));       // serve the website files

app.post("/api/echo", (req, res) => {
  const { text } = req.body;
  if (typeof text !== "string" || !text.trim())
    return res.status(400).json({ error: "text is required" });
  res.json({ echo: text.trim() });
});

app.listen(process.env.PORT || 3000);

5 · Check

Say your answer out loud first, then reveal. Mark “I knew it” for +5 XP each.

What happens if a middleware never calls next() and never sends a response?

The request hangs until timeout — the chain stops and no handler runs.

Why does express.json() need to be registered before the routes that read req.body?

Middleware runs in registration order; the body must be parsed before any handler tries to use it.

6 · Interview

Walk me through a request hitting your Express server.

It enters the middleware chain in registration order (parsing, logging, limits), matches a route by method+path, the handler validates input, does its work, and sends a JSON response with the right status code.

What is middleware, in one sentence?

A function in the request pipeline that can inspect or modify req/res and decides whether the request continues to the next stage.
