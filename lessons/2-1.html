Goal — by the end of this lessonBy the end you can use Python's core data structures idiomatically — comprehensions over loops, the right container for the job, and functions with clean inputs and outputs.

1. Pick the container by the question you ask

▶ YouTube reference — the video for this lesson

  • list — ordered, changeable: "give me item 3", "append this".
  • tuple — ordered, fixed: coordinates, a (node, edge) pair that must not change.
  • dict — key → value lookup: a lesson record, JSON data. The workhorse.
  • set — uniqueness and membership: "have I seen this id?" in O(1).

Choosing wrongly is how O(n²) accidents happen — scanning a list for membership inside a loop, where a set would be instant.

3. Functions as pipelines

▶ YouTube reference — the video for this lesson

Skillzify's flowchart scripts are chains of small functions: parse → transform → emit. Each takes data in and returns data out, with no hidden globals — which is why they are testable one at a time in PyCharm's debugger. Prefer that style over one giant script: a bug in a 10-line function is a 10-line search.

Working setupDo this module in PyCharm with a virtual environment per project (venv) and pip for packages. Environment hygiene — never installing into the system Python — is a professional habit, not trivia.
Watch out — common mistakes
  • Scanning a list for membership inside a loop (O(n²)) where a set gives O(1).
  • Writing C-style index loops in Python instead of iterating values and using comprehensions.

When is a set the right container instead of a list?

When the questions are uniqueness and membership ('have I seen this?') — set lookup is O(1) versus O(n) scanning a list.

Why keep functions pure (data in, data out) in the flowchart scripts?

Each stage can be tested and debugged independently in PyCharm; hidden global state makes failures non-local and hard to reproduce.

7 · Interview ▾

List vs tuple vs set vs dict — when each?

List: ordered mutable sequence. Tuple: fixed record. Set: uniqueness/membership. Dict: key-based lookup — the default workhorse.

What is a comprehension and why prefer it?

A compact expression building a collection from another; it reads as a sentence and is the idiomatic Python way to map/filter.
