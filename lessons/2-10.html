1. NumPy: lists with superpowers

▶ YouTube reference — the video for this lesson

▸ Code example — see the Code section below.

Operations apply to the whole array at once (vectorisation), running in compiled code — often 10–100× faster than a Python loop, and shorter to read. An array also has a shape: a list of scores is (4,), a table of 30 learners × 5 scores is (30, 5). Shapes are the grammar of AI data.

2. Embeddings are just arrays

▶ YouTube reference — the video for this lesson

In Module 5 you'll meet embeddings: texts converted to vectors like (384,) or (768,) numbers. Similarity between two texts becomes arithmetic between two arrays (a dot product). Every RAG system you build later is, at the bottom, NumPy-style array maths — which is why this lesson sits here.

3. Pandas: tables with labels

▶ YouTube reference — the video for this lesson

▸ Code example — see the Code section below.

A DataFrame is a spreadsheet you program: labelled rows and columns, filtering, grouping and joins without hand-written loops. Use it for datasets, logs and evaluation results (Module 5's evals are a DataFrame-shaped problem).

Scope disciplineYou need literacy, not mastery: arrays, shapes, slicing, mean/filter, read_csv, groupby. Deep data-science technique belongs to a data track; this is the AI-engineering minimum.
Watch out — common mistakes
  • Writing Python loops over arrays when a vectorised operation exists.
  • Ignoring array shapes until a broadcasting bug produces a silently wrong result.

3 · Code

import numpy as np
scores = np.array([40, 55, 80, 92])
scores.mean()          # 66.75 — whole-array maths, no loop
scores[scores >= 50]   # array([55, 80, 92]) — boolean filtering
import pandas as pd
df = pd.read_csv("learners.csv")
df.groupby("section")["xp"].mean()   # average XP per section, one line

Why is scores.mean() preferred over a hand-written loop?

It's vectorised: the operation runs over the whole array in compiled code — faster, shorter, and less error-prone than manual accumulation.

What is an embedding, in array terms?

A vector — a fixed-length NumPy-style array of numbers representing a text's meaning, so similarity becomes array arithmetic.

6 · Interview

Why is NumPy faster than pure Python loops?

Operations run vectorised in compiled code over contiguous typed arrays, instead of per-element Python interpreter work.

What is an embedding, technically?

A fixed-length float vector produced by a model such that semantic similarity corresponds to geometric closeness (cosine/dot product).
